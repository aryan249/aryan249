## 💼 What I Work On

### 🔧 Backend Services & APIs
- Design and build **REST APIs and gRPC microservices** in TypeScript and Go
- Handle **high-concurrency workloads** using goroutines, channels, and async patterns
- Build **WebSocket servers** for real-time data delivery with sub-50ms latency
- Implement **JWT authentication**, JWKS-based role access control, and rate limiting
- Write **unit, integration, and suite-based tests** ensuring production reliability

### 📨 Event Streaming & Messaging
- **Kafka** and **Redis Streams** for event-driven microservice communication at 10,000+ events/sec
- Consumer group patterns, at-least-once delivery, and deduplication
- **Redis pub-sub** for cross-server state consistency in multi-region deployments
- **Stampede lock** on Redis cache to prevent thundering herd issues

### 🗄 Databases & Caching
- **PostgreSQL** — schema design, query optimization, migrations, connection pooling
- **Redis** — caching strategies, configurable expiry, cache invalidation mechanisms
- **MongoDB** for NoSQL workloads
- Reduced API latency from **2s → 300ms** through caching architecture redesign

### ☁️ Infrastructure & DevOps
- **Kubernetes** — Helm, ArgoCD GitOps, Pod Disruption Budgets for availability
- **AWS** — ECS, EKS, S3, EC2 
- **GitHub Actions** CI/CD pipelines — build, test, deploy to production
- **Prometheus + Grafana** for metrics, alerting, and availability monitoring
- **Sentry** for error tracking and latency monitoring

### 🔗 Blockchain & Web3 Backend
- Built backend services for a full **perpetual futures DEX** — order matching, settlement, collateral management
- Designed **Solidity smart contracts**
